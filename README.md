# QuickServe

QuickServe is a modern service-booking web application that connects customers with trusted local service providers.

## 🚀 About The Project

QuickServe makes it easier for customers to discover local professionals, explore services, view provider profiles, and request a service from one simple platform.

## ✨ Features

- Responsive modern homepage
- Services page with service categories
- Provider listing with search and filters
- Individual provider profile pages
- Service booking form
- Booking summary
- Customer Login & Sign Up pages
- Responsive mobile navigation
- AI Chat Assistant UI
- Mobile-friendly responsive design
- Clean and user-friendly interface

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages
